dependencies. It implements the A2A 1.0 JSON-RPC wire format directly with Node
built-ins.

bundle the `@a2a-js/sdk`, whose Apache-2.0 license and notices remain with the
main Zesia repository under `THIRD_PARTY_NOTICES.md` when that SDK is used there.
